justniaaOS Wiki

justniaaOS is a private HTML browser for previewing websites, experimenting with code, and keeping track of your favorite links.

  • Address bar: Type any URL or search query to load through your Node.js proxy.
  • Code Mode ({}): Write HTML, CSS, and JS and click Update preview.
  • Privacy: Notes, history, favorites, and themes stay stored locally in your browser.
